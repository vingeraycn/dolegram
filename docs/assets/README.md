# Visual assets

- `dolegram-icon.png`: the Dot ring with a small matching ice-blue (`#7CCBFF`) Telegram paper plane centered inside its opening; transparent exterior and space around the plane.
- `dolegram-logo.png`: horizontal icon and wordmark for the README.
- `how-it-works.png`: the Telegram → Mac → Dot round trip, with a separate return path.

Created with the built-in image generation tool. The ring shape follows the public graphic in OpenAI's [Introducing dots](https://openai.com/index/introducing-dots/) announcement; the source graphic is [dots-o.svg](https://images.ctfassets.net/kftzwdyauwt9/KKSjto3MtJguvsLQsM1Bp/1704a6937d22b1bb3cac38dc5f43f9df/dots-o.svg). The composite is project artwork, not an official OpenAI or Telegram logo or endorsement. Brand references do not grant trademark rights or an open-source license.

Keep diagrams aligned with the actual local bridge. Incoming text reaches the host through signed MCP Events; authorized tools return through the private MCP Tunnel, and dolegram writes to Telegram through the Bot API. Do not imply instantaneous replies or that all message processing stays on the Mac.

The website hero (`../web/hero.png`) is a generated decorative interpretation of the ring-and-plane mark. Website text, controls and animated conversation remain native HTML/CSS/JavaScript. The brand accent is ice blue `#7CCBFF`; the marketing site uses a near-black `#090B10` background.
