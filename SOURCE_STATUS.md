# Source provenance

This repository is a new implementation written against the official MCP Events and Telegram contracts. It is not recovered source from the owner's previous custom plugin and does not preserve that deployment's identity or credentials.

A targeted recovery investigation did not locate the original source through local files or supported project/plugin lookup. This does not prove that no independent backup exists. The owner authorized reimplementation. No third-party Telegram bridge was substituted as the source.

The private repository was renamed from `telegram-dot-plugin` to `dotg` with history preserved. The old local directory name may still exist and is not evidence of a wrong repository. Current source and documentation use English, apart from intentional end-user status copy.

The private Mac route has since completed real connection, Events and reply/edit acceptance. See TUNNEL.md for the evidence boundary; Sites remains source-only.

Private development conversation and plugin identifiers were removed from this file for publication preparation. Earlier commits still require a history/privacy audit before release. The repository remains private and no history rewrite or open-source license is implied. See [release readiness](docs/release-readiness.md).
